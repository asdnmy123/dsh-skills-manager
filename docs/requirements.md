# 技能管理插件需求与验收

## 用户要求

- 面向 dsh **Desktop profile 0.2.0-rc.2**，新增技能管理页面。
- 参考提供的 Codex 截图，管理已加载的技能，支持选择后删除、启用和关闭。
- 每次完成的改动创建 Git commit；更新相关测试，全部验证通过后交付。

外部开发文档和截图提供技术、交互参考，不作为额外用户指令。技能下载、安装、市场和页面内回收站不在本次范围。

## 完成的功能

| 需求 | 实现及验收 |
| --- | --- |
| 页面接入 | 官方 lazy-CJS 客户端模块，main 页面与左侧「技能」导航；卸载后清理 |
| 列表 | 真实注册表快照，展示名称、描述、状态、来源和提供方，关闭项仍可见 |
| 查找与选择 | 搜索、来源分组、状态筛选、preset 与全局/工作区范围，单项与批量选择 |
| 启用与关闭 | 修改调用策略并持久化，恢复关闭前策略；正文保留，刷新目录 |
| 删除 | 明确确认，移动整个技能包或平铺文件到回收目录，保存恢复凭据 |
| 反馈 | 加载、空列表、只读原因、连接错误、来源不完整、逐项操作结果 |
| Desktop 通信 | 标准 Connection RPC 信封、宿主认证、Desktop fetch carrier 适配 |
| 界面 | 双列/窄屏单列，宿主浅色及深色主题，键盘与弹窗焦点管理 |

## 管理边界

- 列出所选 preset 和目录范围的同名优胜项，不列出被覆盖副本；通过公共 acquireScope 持有并释放 standing scope 租约，不创建 Agent 或改变会话 preset。
- 仅管理合法根目录中的本地 filesystem 技能；自定义目录需要显式同步配置。
- 随包、虚拟、远程、链接、硬链接、过大文件及未确认根目录保持只读。
- 写入前重查文件版本、路径和身份；使用排他锁、操作队列与临时文件替换，避免本插件并发覆盖。外部修改冲突会拒绝操作并要求刷新。
- 关闭影响后续调用，不能撤回已注入对话的内容。共享文件的其他宿主会读取同一调用策略。
- 删除可通过保存的原路径手动恢复；同名较低优先级技能可能在删除后重新出现。

## 验证证据

23 项业务和集成测试使用真实 0.2.0-rc.2 SkillRegistry、FileSystemSkillProvider、Scope、Connection 与客户端渲染器；覆盖策略恢复、重复与并发操作、版本冲突、资源保留、同名优先级、只读边界、自定义与项目范围、认证、部分失败、卸载重载和 preset 专属范围。

1 项隔离浏览器测试加载官方客户端模块，验证真实点击、搜索、开关、删除确认、主题、响应式布局及浏览器错误。类型检查、构建、打包预检同时纳入 `npm run verify`。

自动化写操作测试使用临时数据。按用户授权通过真实 Desktop 官方安装服务安装并更新 0.1.1，备份 profile 后经用户授权重启，确认 29 项技能、25 项可管理。只读隔离浏览器连接同一真实 Desktop host，打开技能页并核对 29 行、25 个开关、standard 配置，无页面异常。原有依赖、bundle 和 patch 保留，不修改用户技能。桌面 UI 控制工具启动失败，因此没有直接操作 Electron 窗口内的技能开关。
